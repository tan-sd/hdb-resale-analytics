## Installation

### Clone
Clone the github repository to your local machine by typing in the terminal `git clone https://github.com/tan-sd/hdb-resale-analytics.git`

### Project setup
```
cd hdb-resale-analytics

npm install
```

### Running Development Server
```
npm run dev
```
